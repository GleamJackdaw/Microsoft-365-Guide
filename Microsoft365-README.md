## 📌 What is Microsoft 365?

Microsoft 365 is Microsoft's **productivity and collaboration suite**, bundling desktop, web, and mobile apps like Word, Excel, PowerPoint, and Outlook with cloud services (OneDrive, Teams, SharePoint) under a subscription model — while a one-time-purchase version of core Office apps is also still available.

## ✨ Key Features

| Feature                     | Description                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| Word, Excel, PowerPoint          | Core document, spreadsheet, and presentation apps                  |
| Outlook & Exchange                | Email, calendar, and contacts, with business-grade hosting          |
| Microsoft Teams                    | Chat, video meetings, and collaborative workspaces                    |
| OneDrive Cloud Storage               | File sync and sharing integrated across all apps                       |
| Microsoft Copilot                     | AI-powered writing, data analysis, and slide generation assistance      |
| Real-time Co-authoring                 | Multiple users editing the same document simultaneously                   |
| Cross-platform Apps                     | Full apps for Windows, macOS, iOS, Android, and the web                    |

## 💰 Pricing & Plans

| Plan                          | What's Included                                        |
| ---------------------------------- | ------------------------------------------------------ |
| Microsoft 365 Personal/Family    | Full app suite + cloud storage, subscription-based        |
| Microsoft 365 Business plans       | Adds Teams, Exchange, and admin/security tools for organizations |
| Office Home & Student (Perpetual)   | One-time purchase of core apps, no subscription required   |
| Education Pricing                    | Discounted or free plans for students and educators           |

👉 Exact current prices and regional availability: [microsoft.com/microsoft-365/buy](https://www.microsoft.com/microsoft-365)

## 🚀 How to Get Started

1. Go to the official page → [microsoft.com/microsoft-365](https://www.microsoft.com/microsoft-365)
2. Choose a Personal, Family, Business, or one-time-purchase plan.
3. Create/log in to your Microsoft account.
4. Subscribe or purchase, then install via the Microsoft 365 web portal.
